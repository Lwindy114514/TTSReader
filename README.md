# 有声小说播放器（NovelTTSPlayer）

本地 TXT 小说的流式 TTS 朗读播放器。针对超长文本（数百万字、数十 MB）优化：边读边流式读取，不整本加载到内存，支持断点续播、后台/锁屏播放与通知栏控制。

## 功能

- **本地 TXT 导入**：通过系统文件选择器添加任意编码的小说文本
- **编码自动识别**：UTF-8（含 BOM）、GBK、GB18030 自动检测，无需手动指定
- **流式读取**：按章节/自然段流式切分，几 MB~几十 MB 文件秒级加载并建立章节索引，内存占用稳定（4.9MB/约 164 万字文件实测 PSS ≈124MB）
- **连续朗读**：自动跨段、跨行、跨章连续播报，至末尾自动停止并提示
- **断点续播**：实时自动保存进度，重新打开 App 提供"继续阅读"恢复；杀掉进程后也能精确恢复到原位置
- **双位置“继续阅读”**：TTS 播放位置与手动阅读位置**分开持久化**（各自含时间戳）。点击“继续阅读”时自动取两者中时间较新者作为恢复位置：手动读到第55段后再退出，即使 TTS 还停在更早段落，也会回到第55段；反之亦然。只有旧版 TTS 断点的书自动兼容
- **段落导航**：上一段 / 下一段（跳过空行，定位准确）
- **后台与锁屏播放**：前台服务 + 媒体会话，按 Home / 锁屏后继续播放，媒体面板（上一首/暂停/下一首）可直接控制
- **语音引擎切换**：TTS 设置对话框列出已安装引擎（系统/厂商/联网），一键切换
- **中文语音固定**：TTS 设置 → "中文语音…" 可固定选定的中文离线语音（如 Google 的"语音II"= `cmn-cn-x-ccd`），App 每次启动自动通过 `setVoice` 应用，不依赖易被重置的系统默认语音
- **章节目录与跳转**：自动识别多种章节格式（第N章/回/卷/部/集、中文与阿拉伯数字、前导零、卷一、Chapter N、序章/楔子/番外/终章等），正文中的"第N章…"句子不会误判；目录以 BottomSheet 展示，超多章节流畅滚动，当前章高亮并自动定位；点章节即跳转（播放中则从该章起重新朗读）
- **Reading Block 合并阅读/朗读**：把过短的 TXT 段落按显示/朗读上限动态合并为「阅读块」，长段落与章节标题各自独立成块，块不跨章节。阅读块是阅读显示、TTS 一次朗读、上一段/下一段一次跳转、断点定位的**统一单位**（原始 TXT 段落结构保持不变，仅运行时组合）
- **上一章/下一章**：播放界面一键切章
- **超大文件章节索引**：章节索引流式扫描并落盘缓存（按文件大小+修改时间指纹），再次打开毫秒级加载，不整读文件、不 OOM
- **播放异常自恢复**：引擎单句失败自动重建重试；引擎长时间无回调（卡死）时看门狗自动重启引擎，连续多次无响应则提示切换引擎
- **语速/音调调节**：保存设置，播放前自动应用

## 构建

环境：JDK 17、Android SDK 34（compileSdk 34 / minSdk 26 / targetSdk 34）

```bash
gradlew.bat assembleDebug
```

产物：`app/build/outputs/apk/debug/app-debug.apk`

## 安装与使用

```bash
adb install -r app-debug.apk
```

1. 打开 App，点"添加小说"，从文件选择器选择 TXT 文件（文件名含中文亦可）
2. 点书库中的书名进入播放界面，点"播放"
3. 如需换语音引擎：点右上角 TTS 按钮 → 选择引擎（如遇到持续无声，优先选择 Google TTS）
4. 固定语音（可选）：点 TTS 按钮 → "中文语音…" → 选"语音II（ccd）"，之后每次启动都自动用该语音，无需再进系统设置
5. 章节目录：播放界面点「目录」查看全部章节并跳转（当前章高亮）；或直接用「上一章 / 下一章」切章
4. 中途退出：按 Home 或锁屏即可继续朗读；通知栏/媒体面板可暂停、上/下一段
5. 再次打开 App 点"继续上次播放"即可从上次位置恢复

## 已知问题

- **OPPO/ColorOS 自带 TTS 引擎**（com.oplus.ttsaccessibilityengine）在较大文件上播报 1~2 段后可能内部卡死（不再回调）。App 内置看门狗会尝试自动恢复；若持续无声，请在 TTS 设置中切换到 **Google TTS**（实测稳定）。
- ColorOS 日志中会出现 "AudioHardening background playback would be muted" 提示，属系统监控日志；实测后台播放音频轨道为 started 且未静音，不影响收听。
- 部分 ColorOS 版本对 TTS 引擎的包可见性限制已通过 `<queries>` 声明解决；若系统字体/无障碍等权限受限，需在系统设置中允许。
